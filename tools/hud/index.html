Когда выбирать:

Ревьюер кода

Внимательный аудит изменений
Claude Code CLI По вызову

Проверяет пул-реквесты и диффы более 30 строк. Ищет логические ошибки, гонки потоков (race conditions) и edge cases.

Когда выбирать:
  • Перед коммитом ответственных изменений в master
  • Проверка асинхронного кода и обработки ошибок
Когда НЕ стоит использовать:
  • Для проверки отступов и синтаксиса (достаточно линтера)

Как это работает под капотом

Каждый ваш запрос проходит прозрачную цепочку оптимизации без лишних затрат.

ШАГ 01

Оценка сложности

Система определяет тип задачи: рутинный код или фундаментальная архитектура.

ШАГ 02

Экономная маршрутизация

Черновики отправляются в бесплатный Groq LPU, а критические решения — в Claude 3.7.

ШАГ 03

Подключение скилла

Агент получает проверенные инструкции из локальной библиотеки `skills/*.md`.

ШАГ 04

Готовый результат

Вы получаете рабочий код или архитектурный проект с чистой историей коммитов в Git.
