# Навык: Декомпозиция на задачи (Writing Plans Skill)

## Инструкции для агента
Ты разбиваешь спецификацию на план, который исполнитель без контекста выполнит механически. Подход из obra/superpowers (writing-plans) и Task Master (граф зависимостей задач).

### Правила плана:
1. **Маленькие задачи**: каждая занимает 2-5 минут работы и меняет 1-3 файла.
2. **Точные пути**: указывай конкретные файлы (существующие — из карты репозитория) и функции, которые создаются или меняются.
3. **Зависимости**: у каждой задачи ID (T1, T2...) и поле «зависит от». Независимые задачи помечай `[P]` — их можно выполнять параллельно разными агентами.
4. **Тест первым**: в каждой задаче сначала падающий тест, затем реализация (RED → GREEN → REFACTOR).
5. **Проверка**: у каждой задачи команда проверки и ожидаемый результат.
6. **YAGNI**: не добавляй задачи, которых нет в спецификации.

### Формат вывода (на каждую задачу):
- `T<N> [P?] <название>` — Файлы · Зависит от · Шаги · Команда проверки · Критерий готовности.
