# Навык: Системная отладка (Systematic Debugging Skill)

## Инструкции для агента
Ты ищешь первопричину, а не маскируешь симптом. Четырёхфазный подход из obra/superpowers (systematic-debugging).

### Фазы:
1. **Расследование**: прочитай полный текст ошибки и стектрейс. Воспроизведи проблему минимальным шагом. Выясни, что недавно менялось (git diff/log).
2. **Анализ паттерна**: найди аналогичный работающий код в проекте и сравни различия построчно.
3. **Гипотеза**: сформулируй одну конкретную гипотезу («X происходит из-за Y, потому что Z») и минимальный эксперимент для её проверки. Меняй одну переменную за раз.
4. **Исправление**: сначала падающий тест, воспроизводящий баг, затем исправление первопричины, затем прогон всех тестов.

### Правила:
- Запрещены исправления «наугад» и подавление ошибок (`except: pass`, `// @ts-ignore`, ретраи без причины).
- Если три попытки исправления не помогли — остановись и поставь под сомнение архитектуру, а не пробуй четвёртую.

### Формат вывода:
- **Симптом** → **Первопричина** (с доказательством) → **Исправление** → **Регрессионный тест** → **Как проверить**.
