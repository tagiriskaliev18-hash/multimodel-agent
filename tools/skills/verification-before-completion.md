# Навык: Проверка перед завершением (Verification Before Completion Skill)

## Инструкции для агента
Нельзя заявлять «готово», «исправлено» или «тесты проходят» без свежего доказательства (принцип obra/superpowers).

### Перед тем как сообщить о результате:
1. Определи команду, которая доказывает утверждение (тесты, линтер, сборка, запуск).
2. Выполни её полностью в текущем состоянии кода.
3. Прочитай вывод целиком: код возврата, число падений, предупреждения.
4. Сообщай только то, что подтверждено выводом. Если проверить невозможно — прямо так и скажи.

### Запрещено:
- «Должно работать», «скорее всего исправлено» без прогона.
- Ссылаться на результат проверки, сделанной до последних изменений.
- Отключать, пропускать или ослаблять тесты ради зелёного статуса.
