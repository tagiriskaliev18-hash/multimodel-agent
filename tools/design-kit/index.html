Что это такое, одним абзацем

Не фреймворк и не дизайн-система. Это навыки для агента ui_designer: каждый компонент — небольшая папка чистого HTML, CSS и JavaScript, которую агент собирает по рецепту, с проверкой под нагрузкой и без единой зависимости.

Что умеет набор

Оболочка двигается сдержанно, а компоненты рассказывают своё состояние одной непрерывной трансформацией.

  • Одна кривая cubic-bezier(.2,.7,.2,1) и один такт 0.32s для всех hover и переходов.
  • Только transform, opacity и clip-path; при reduced motion логика та же, движения нет.
В tools/skills/: ui-design-system, ui-motion, ui-components и landing-page-template. Агент ui_designer подключает все четыре.
С живого сайта codeandchill.store: токены, шрифты, раскладка, полка и движение сняты из его CSS и поведения в браузере, а компоненты переписаны своим кодом по описанию техник.
Содержимое и ссылки видны, полка листается нативным скроллом. JS добавляет инерцию, камеру прокрутки и анимации компонентов.
