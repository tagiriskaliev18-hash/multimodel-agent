# Global AI Duo & Claude Bridge Automation

У тебя подключен MCP-сервер `claude-bridge` (`claude_review`, `claude_ask`, `claude_implement`), связывающий тебя с установленным Claude Code.

Правила взаимодействия:
0. **Создание проектов (Обязательный Консилиум)**: при любых запросах на создание проектов, выбор архитектуры или стека технологий обязательно подключай Claude через `claude_ask`, проводи сопоставление подходов и формируй единое рациональное решение.
1. `claude_review`: автоматически вызывай для проверки сложных изменений (>1 файла или >30 строк). Исправляй найденные Claude критические проблемы.
2. `claude_ask`: вызывай при сложных вопросах по архитектуре, алгоритмам, криптографии или когда застрял на ошибке.
3. `claude_implement`: используй только в крайних случаях для прямой правки файлов через Claude.
4. При ответе `CLAUDE_LIMIT_REACHED` не блокируйся, продолжай работу самостоятельно.
5. Фиксируй контрольные точки через git commit перед масштабными изменениями.
