# Global AI Duo & Multi-Model Architecture (powered by Claude & LLM Soup)

У тебя подключены глобальные MCP-серверы:
- `claude-bridge` (`claude_review`, `claude_ask`, `claude_implement`, `model_ask`, `models_list`, `soup_recipe`), связывающий тебя с Claude Code, локальными моделями (Ollama / GGUF) и API-провайдерами по образцу реестра LLM Soup.
- `soup` (`advise`, `recipes_search`, `diagnose_evidence`, `ship_evidence`, `profile` и др.), предоставляющий инструменты LLMOps от Alpamys Makazhan.

Правила взаимодействия:
0. **Создание проектов (Обязательный Консилиум)**: при любых запросах на создание проектов, выбор архитектуры или стека технологий обязательно подключай Claude через `claude_ask`, проводи сопоставление подходов и формируй единое рациональное решение.
1. `claude_review`: автоматически вызывай для проверки сложных изменений (>1 файла или >30 строк). Исправляй найденные критические проблемы.
2. `claude_ask` / `model_ask`: вызывай при сложных вопросах по архитектуре, алгоритмам или для получения альтернативного мнения от других моделей из `providers.json`.
3. `claude_implement`: используй только в крайних случаях для прямой правки файлов через Claude.
4. При ответе `CLAUDE_LIMIT_REACHED` не блокируйся, переключайся на другие модели через `model_ask` или продолжай работу самостоятельно.
5. Фиксируй контрольные точки через git commit перед масштабными изменениями.
