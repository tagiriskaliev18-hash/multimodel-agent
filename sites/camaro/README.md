# Camaro 3D — промо-сайт

Одностраничный промо-сайт Chevrolet Camaro с настоящей 3D-моделью на Three.js (r160, грузится с jsDelivr). Без сборки.

Запуск: страница загружает модель через XHR, поэтому её нужно открывать с веб-сервера, а не как файл:

```
cd sites/camaro && python3 -m http.server 8000
# http://localhost:8000
```

## Что внутри
- Ночная дорога со сдвоенной жёлтой разметкой и столбиками-отражателями, свет фар, отражения на лаке.
- Машина въезжает при загрузке; колёса вращаются от скорости.
- Камера переходит между ракурсами по скроллу: 3/4 спереди, профиль, вид сзади при езде, конфигуратор, вид сверху, корма, финал.
- «Поехали»: кнопка «Газ» (или пробел) разгоняет машину до 250 км/ч, спидометр и тахометр с передачами.
- Конфигуратор: 8 заводских цветов перекрашивают 3D-кузов, 5 версий с характеристиками, машину можно крутить мышью или пальцем.
- Таблица версий, история поколений 1967–2024, форма тест-драйва (никуда не отправляет данные).
- Адаптив до 390px: на телефоне машина сверху, панели снизу.

## Модель
`camaro.gltf.json` — glTF 2.0 с встроенным бинарным буфером (текстуры WebP). Страница собирает из него GLB в памяти.

3D-модель «Chevrolet Camaro»: автор GregX, https://sketchfab.com/3d-models/chevrolet-camaro-dee5eed83d2442c49ce360e87ef08ef1, лицензия CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Изменения: текстуры уменьшены до 1024px и переведены в WebP, материал кузова заменяется в коде на лак с clearcoat.
