# DuoOS

**DuoOS** — операционная система для разработчиков, собранная на Linux. Внешне она похожа на macOS, а по устройству ближе к Linux Mint: знакомая логика, стабильная LTS-основа и никаких snap. Работает на любом x86-64 компьютере с любой видеокартой: AMD, Intel или NVIDIA.

> По ощущениям это «Хакинтош», но без его ограничений. Не нужно подбирать железо, NVIDIA и AMD поддерживаются, лицензию Apple система не нарушает, а обновления не ломают загрузку.

| | |
|---|---|
| Основа | Ubuntu 26.04 LTS, поддержка до 2031 года (как у Linux Mint) |
| Ядро | Linux 7.0 |
| Рабочий стол | KDE Plasma 6.6 (Wayland) в раскладке «строка меню + док» |
| Графика | Mesa 26 (AMD, Intel, NVIDIA через NVK) и фирменный NVIDIA 580 в один клик |
| Установщик | Calamares: пошаговый мастер, как у Windows |
| Файловая система | Btrfs со снимками Timeshift. Перед каждым обновлением создаётся снимок, откат делается одной кнопкой |
| Приложения | deb-пакеты Ubuntu и Flathub через «Центр приложений» (Discover) |

## Что взято у каких систем

**От macOS**
- Строка меню сверху с глобальным меню приложения и значком системы.
- Плавающий док снизу по центру и полноэкранный список приложений, аналог Launchpad.
- **Meta+Space** открывает поиск по приложениям, файлам и калькулятор, аналог Spotlight.
- **Meta+W** или угол экрана слева снизу открывает обзор всех окон, аналог Mission Control.
- Кнопки окна в виде «светофора» слева, размытие, скруглённые углы, шрифт Inter.

**От Linux Mint**
- Центр приветствия и менеджер драйверов.
- Снимки системы Timeshift.
- Никаких snap, приложения ставятся из deb и Flatpak.
- Стабильная LTS-основа, привычное меню, полная настраиваемость.

**От Windows**
- Установщик-мастер: язык → регион → клавиатура → диск → пользователь → установка.
- Установка рядом с Windows с выбором системы при загрузке.
- Переключение раскладки по Alt+Shift.

**Для программистов (сразу из коробки)**
- VS Code, Git, GitHub CLI, lazygit.
- Docker, Podman, Distrobox.
- Python, Node.js, rustup, GCC/Clang, CMake, Neovim.
- Терминал kitty с отрисовкой на GPU, zsh с автоподсказками и подсветкой, starship, fzf, zoxide, ripgrep, bat, eza.
- «Инструменты разработчика» ставят в один клик Java, Go, .NET, Rust, JetBrains IDE, Android Studio, Ollama и Claude Code.

## Как скачать

Готовый образ публикуется на странице **[Releases](https://github.com/tagiriskaliev18-hash/multimodel-agent/releases)**. Файл называется `duoos-1.0-amd64.iso`.

Если образ больше 2 ГБ, он разбит на части `.part0`, `.part1`. Скачайте все части и запустите `join-windows.bat`: он склеит их в один ISO.

## Установка на компьютер с флешки

1. Возьмите флешку на 8 ГБ или больше. Все данные на ней будут удалены.
2. Запишите ISO одной из программ:
   - **[Rufus](https://rufus.ie)** (Windows). Выберите ISO и нажмите «Старт». Если Rufus спросит про режим записи, выберите **«DD-образ»**.
   - **[balenaEtcher](https://etcher.balena.io)** (Windows, macOS, Linux). Выберите ISO, затем флешку и нажмите Flash.
   - **[Ventoy](https://www.ventoy.net)**. Достаточно скопировать ISO на флешку.
3. Вставьте флешку в компьютер и при включении вызовите меню загрузки. Обычно это **F12**, **F11**, **F8** или **Esc**, у ноутбуков HP — **F9**. Выберите флешку.
4. В меню DuoOS выберите **«Установить DuoOS»**. Установщик откроется сам.
5. Пройдите мастер. На шаге «Диск» можно выбрать:
   - **Стереть диск** — DuoOS будет единственной системой;
   - **Установить рядом** — рядом с Windows, выбор системы при каждом включении.
6. После установки перезагрузитесь и извлеките флешку.

Secure Boot включать и выключать не нужно: загрузчик подписан, как в Ubuntu.

## Установка в VMware Workstation / Player

1. **Создать новую виртуальную машину** → «Типичная» → «Файл образа установочного диска (iso)» → выберите `duoos-1.0-amd64.iso`.
2. Гостевая ОС: **Linux → Ubuntu 64-bit**.
3. Ресурсы: **4 ГБ ОЗУ и больше** (лучше 8), **2–4 ядра**, **диск 40 ГБ и больше**.
4. «Настроить оборудование» → «Дисплей» → включите **«Ускорение 3D-графики»**.
5. Для UEFI: «Параметры» → «Дополнительно» → **UEFI**. Можно оставить и BIOS, работают оба режима.
6. Запустите ВМ и выберите «Установить DuoOS».

VMware Tools (`open-vm-tools`) уже встроены. Автоматически работают общий буфер обмена, перетаскивание файлов и изменение разрешения под размер окна.

В VirtualBox, Hyper-V и QEMU/KVM система тоже работает, гостевые дополнения для них предустановлены.

## Первые шаги после установки

- Откроется **Центр DuoOS**. Если в компьютере NVIDIA, он сразу предложит фирменный драйвер.
- Обновления выполняются в «Центре приложений» → «Обновления» или командой `update` в терминале.
- Если после обновления что-то сломалось, откройте **Timeshift** и восстановите снимок «Перед обновлением пакетов».

## Системные требования

| | Минимум | Рекомендуется |
|---|---|---|
| Процессор | x86-64, 2 ядра | 4 ядра и больше |
| Память | 4 ГБ | 8–16 ГБ |
| Диск | 25 ГБ | 60 ГБ, SSD |
| Видеокарта | любая (AMD, Intel, NVIDIA; режим «Безопасная графика» для очень старых) | |

## Сборка образа самостоятельно

Нужен Ubuntu или Debian с правами root и около 30 ГБ свободного места:

```bash
sudo apt install debootstrap squashfs-tools xorriso grub-pc-bin grub-efi-amd64-bin mtools dosfstools
sudo ./os/build.sh          # полная сборка → os/out/duoos-1.0-amd64.iso
sudo ./os/build.sh iso      # пересобрать только ISO из готовой системы
sudo ./os/build.sh clean    # удалить рабочие файлы
```

Сборка на GitHub запускается автоматически при каждом изменении в `os/` (workflow `.github/workflows/build-iso.yml`), а результат публикуется в Releases. Запустить сборку вручную можно так: вкладка **Actions** → «Сборка DuoOS ISO» → **Run workflow**.

### Устройство репозитория

```
os/
├── config.env                  имя, версия, база Ubuntu, язык по умолчанию
├── build.sh                    сборка: debootstrap → пакеты → squashfs → ISO (BIOS+UEFI+Secure Boot)
├── packages/*.list             списки пакетов по группам
├── scripts/chroot-setup.sh     настройка системы внутри образа
├── iso/                        меню загрузки GRUB и его тема
├── overlay/                    файлы, которые кладутся в систему поверх Ubuntu
│   ├── etc/calamares/          установщик: шаги, разметка Btrfs, оформление
│   ├── etc/xdg/                настройки KDE по умолчанию (тема, шрифты, клавиши)
│   ├── etc/skel/               настройки нового пользователя (zsh, kitty, VS Code, git)
│   └── usr/…                   Центр DuoOS, тема окон, обои, раскладка рабочего стола
└── assets/                     генераторы графики (логотип, обои, тема окон)
```

Название, версия и язык системы меняются в `os/config.env`. Графику можно перегенерировать командами `python3 os/assets/make-assets.py` и `python3 os/assets/make-aurorae.py`.
